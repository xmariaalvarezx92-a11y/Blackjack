# Blackjack en JavaScript

Proyecto del Videojuego Blacjack sencillo desarrollado por María Álvarez Castillo.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript
* Canvas

## Funcionalidades

* Baraja aleatoria
* Sistema de puntuación
* Crupier automático
* Sonidos de cartas
* Música de fondo
* Reinicio de partida

## Cómo ejecutar

Abrir el archivo index.html en un navegador web.
