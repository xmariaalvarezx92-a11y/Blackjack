# Blackjack en JavaScript

Proyecto desarrollado para la asignatura de prácticas.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript
* Canvas

## Funcionalidades

* Baraja aleatoria
* Sistema de puntuación
* Crupier automático
* Sonidos de cartas
* Música de fondo
* Reinicio de partida

## Cómo ejecutar

Abrir el archivo index.html en un navegador web.
